### ご依頼：支援者向けサイト assist.seijiselect.jp の本実装（約1ヶ月・MVP）

お世話になっております。
支援者向けサイトを、**支援リソース台帳ではなく「政治活動支援マッチングサイト」**として再設計しました。本実装をお願いしたくご連絡します。
コンセプトは「**あなたのスキル・人脈・場所・機材が、政治を動かす力になる**」。完成済みプロトを流用→Supabase接続→Vercel公開で、1ヶ月程度を目安にしています。

**■ 対象**
- リポジトリ: `assistant-vote-match`（ブランチ `prototype`）
- 仕様書: repo内 `docs/実装仕様書_支援者側_MVP.md` ／ コンプラ: `docs/コンプライアンス・リスク一覧.md`
- 起動: `npm install` → `npx next dev`（画面は `app/prototype/` 配下、`/prototype` がMVPトップ）

**■ MVP**
LP型トップ／支援できること診断（30秒・登録不要）／募集中の支援／支援者登録（選択式）／支援マッチング／支援実績・バッジ／メッセージ／マイページ。

**■ 進め方（重要）**
- 画面は完成済みなので**作り直さない**でください。
- バックエンドは作らず **Supabase**、公開は **Vercel**。
- 現状 assist は各画面が localStorage を直接利用しています。**まず保存処理を `app/prototype/_store.ts` に集約**し、その1ファイルを Supabase に差し替える進め方を推奨します（他サイトと同様の方針）。

**■ 他サイト・運営adminとの連携（同一Supabase）**
- **募集案件（support_requests）は政治家側が登録**。assist は公開分を表示・応募。
- **支援リソースの本人/法人/運営確認・公開可否の審査は運営admin**（運営OS「支援リソース管理」）。

**■ 今回やらないこと（別フェーズ）**
- 寄付・有償業務の**実決済・本人確認・法令対応**（記録・表示のみ）。
- 実AI（LLM）接続・スクレイピング・後回し機能。

**■ 注意点（コンプラ）**
- 登録・応募・依頼画面に法令注意文を表示。**国籍・属性を申告・確認**（外国籍・外国法人等からの寄付・物品提供は禁止）。
- **「有償業務」は選挙運動を除く**（選挙運動の有償依頼は扱わない）。公開範囲（一般公開/政治家のみ/承認制/非公開）を必ず選べるように。要配慮個人情報は RLS で保護。

まず仕様書 §7「実装順序」Phase 3 以降（募集案件・応募→マッチング→実績/バッジ）の見積もり・進め方をご相談させてください。よろしくお願いいたします。
